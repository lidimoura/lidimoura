## Featured projects

### Amazô.Guia G10 — AI agent with RAG

An individual project developed during **ONE G10**, as part of the **AI for Tech** training program offered by Oracle Next Education in partnership with Alura.

Amazô.Guia G10 is a functional AI agent with RAG, designed to retrieve contextual information and provide more relevant answers based on a knowledge base.

The project demonstrates:

- AI agent development.
- Retrieval-Augmented Generation — RAG.
- Context-aware document and content retrieval.
- Information organization for intelligent interaction.
- Regional digital product development.
- Applied AI for context-oriented user experiences.

The project was developed with support from Hub OS and AI-assisted prototyping and development tools.
