## Projetos principais

### Amazô.Guia G10 — Agente de IA com RAG

Projeto individual desenvolvido no **ONE G10**, dentro da formação **AI for Tech**, programa da Oracle Next Education em parceria com a Alura.

A Amazô.Guia G10 é um agente de IA com RAG funcional, desenvolvido para consultar conteúdos contextualizados e oferecer respostas mais relevantes a partir de uma base de conhecimento.

O projeto demonstra:

- Construção de agente de IA.
- Recuperação aumentada por geração — RAG.
- Consulta contextualizada a documentos e conteúdos.
- Organização de informações para interação inteligente.
- Desenvolvimento de produto digital com foco regional.
- Uso de IA aplicada para criar uma experiência orientada por contexto.

O projeto foi desenvolvido com apoio do Hub OS e utilizando ferramentas de prototipação e desenvolvimento assistido por IA.

### VoeBem ANAC — Pipeline de dados

Projeto desenvolvido durante a **Imersão Pipeline de Dados com Databricks 2026**, da Alura.

A solução utiliza dados públicos da ANAC para construir um pipeline de dados e explorar informações relacionadas ao setor aéreo.

**Tecnologias e conceitos:**

- Databricks.
- Engenharia e pipeline de dados.
- Tratamento e transformação de dados.
- Análise exploratória.
- Integração de dados.
- Aplicação de IA em etapa de finalização.

A imersão em pipeline de dados já foi concluída. O projeto está em evolução, com a camada de IA em fase de finalização.

### Pesquisa de satisfação — Dados e dashboard

Projeto de showcase para demonstrar o ciclo completo de coleta, tratamento, análise e visualização de dados.

```text
Formulário → Base de dados → Google Colab → Python/Pandas → Análise → Dashboard
```

**Inclui:**

- Coleta estruturada de respostas.
- Tratamento e organização dos dados.
- Análise exploratória.
- Indicadores e visualizações.
- Dashboard interativo em Streamlit.
- Possível evolução para Power BI e Tableau.
