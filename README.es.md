## Proyectos principales

### Amazô.Guia G10 — Agente de IA con RAG

Proyecto individual desarrollado en **ONE G10**, dentro de la formación **AI for Tech**, ofrecida por Oracle Next Education en alianza con Alura.

Amazô.Guia G10 es un agente de IA funcional con RAG, desarrollado para consultar contenidos contextualizados y ofrecer respuestas más relevantes a partir de una base de conocimiento.

El proyecto demuestra:

- Desarrollo de agentes de IA.
- Generación aumentada por recuperación — RAG.
- Consulta contextualizada de documentos y contenidos.
- Organización de información para una interacción inteligente.
- Desarrollo de productos digitales con enfoque regional.
- Uso de IA aplicada para crear una experiencia orientada al contexto.

El proyecto fue desarrollado con el apoyo de Hub OS y herramientas de prototipado y desarrollo asistido por IA.

### VoeBem ANAC — Pipeline de datos

Proyecto desarrollado durante la **Inmersión en Pipeline de Datos con Databricks 2026**, de Alura.

La solución utiliza datos públicos de ANAC para construir un pipeline de datos y explorar información relacionada con el sector aéreo brasileño.

**Tecnologías y conceptos:**

- Databricks.
- Ingeniería y pipelines de datos.
- Limpieza y transformación de datos.
- Análisis exploratorio.
- Integración de datos.
- Implementación de IA en fase de finalización.

La inmersión en pipelines de datos ya fue concluida. El proyecto continúa en evolución, con su capa de IA actualmente en desarrollo.

### Investigación de satisfacción — Datos y dashboard

Proyecto showcase que demuestra el flujo completo de recolección, tratamiento, análisis y visualización de datos.

```text
Formulario → Base de datos → Google Colab → Python/Pandas → Análisis → Dashboard
```

**Incluye:**

- Recolección estructurada de respuestas.
- Organización y limpieza de la base de datos.
- Análisis exploratorio.
- Indicadores y visualizaciones.
- Dashboard interactivo en Streamlit.
- Posible evolución hacia Power BI y Tableau.
